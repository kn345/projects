# Kayda Norman — UX Portfolio

React + Vite portfolio site. Design system: warm off-white background,
sage-green accent, warm charcoal text, Fraunces (display) + Inter (body).

## Structure
- `src/pages/` — Home, About, Current Work
- `src/pages/case-studies/` — the five flagship case studies (Capstone,
  Appa Health, AiEmbodied, NerdWallet, VR Chat). Copy is placeholder pending
  final finalized text — see comments at the top of each file.
- `src/components/CaseStudyLayout.jsx` — shared tabbed/scrollable case study
  shell (Overview / Process / Outcome).
- `src/data/caseStudies.js` — homepage card metadata + "Additional Work" list.

## Dev
```
npm install
npm run dev
```
